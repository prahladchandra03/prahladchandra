## 💻 Personal Portfolio Web Application

This repository also contains the full source code for my modern, responsive portfolio web application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

### 🚀 Quick Start (Local Setup)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/prahladchandra03/prahladchandra.git
   cd prahladchandra
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
